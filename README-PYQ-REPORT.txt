TaiyariGhar Updated Pack (Subject-Wise PYQs + Report Question)
=================================================================

Is pack mein yeh naye features jude hain:
1. Subject-Wise Previous Year Questions (PYQs):
   - Bina login kiye bhi open hota hai aur sabke liye free hai.
   - Sahi option pehle se green highlight hota hai, niche explanation hota hai, aur kis exam + kab pucha gaya (ek ya ek se zyada exams) saath mein dikhta hai.
   - Question ke neeche login / Smart Practice / Mock & Live Tests ke links aur promo banner space diya gaya hai taaki first-time visitor aage badh sake.
2. Report Question Option:
   - Unlimited Smart Practice Bank & NCERT ke explanation block mein `⚠️ Report Question` button add kiya gaya hai.
   - Subject-Wise PYQ card mein `⚠️ Report Error` button add kiya gaya hai.
   - CBT Mock/Live test ka `⚠️ Report Q` pehle ki tarah barkarar hai.

Setup:
1. Cloudflare Worker (`taiyarighar-api`) -> Edit code mein `worker.js` paste karke Deploy karein.
2. GitHub Repository Root mein `index.html`, `student-app.js`, `admin-app.js`, aur `tg-admin-bridge.js` replace karein.
