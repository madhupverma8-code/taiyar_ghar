TaiyariGhar Complete Update Pack v5 (PYQ Google SEO + Dark Mode + D1)
=====================================================================

Is single ZIP mein aapke saare features aur Google SEO updates ek saath hain:
1. Google SEO & Auto-Indexing Support for Subject-Wise PYQs:
   - Direct clean URLs: `https://taiyarighar.in/index.html?page=pyq` aur subject-wise `?page=pyq&subject=...`
   - Dynamic `<title>` aur `<meta name="description">` har subject ke mutabik update hota hai.
   - `sitemap.xml` mein PYQ aur NCERT URLs jod diye gaye hain (GitHub par upload karne ke baad Google Search Console mein `sitemap.xml` submit kar dein).
2. Subject-Wise PYQs (Home, Login Page & Candidate Dashboard par card/link):
   - Bina login kiye 100% free, green highlighted sahi option, explanation, exam/year tags, aur niche Login/Practice/Mock Test links.
3. Report Question Option:
   - Smart Practice Bank, NCERT Base, Subject-Wise PYQs, aur CBT Mock/Live Tests—sabhi jagah active.
4. Dark Mode / Light Mode Toggle (`🌙` / `☀️`) header mein.
5. Cloudflare D1 Integration (Practice Bank, NCERT Bank, Subject-Wise PYQs, Mock & Live Tests).
